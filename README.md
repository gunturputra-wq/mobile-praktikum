# Mobile Praktikum

## Tujuan Aplikasi

Aplikasi ini merupakan aplikasi mobile yang dikembangkan menggunakan Flutter
sebagai bagian dari kegiatan praktikum pemrograman mobile.

## Fitur Utama

1. Menampilkan halaman utama aplikasi.
2. Menampilkan informasi aplikasi.
3. Menyediakan navigasi antarhalaman.

## Cara Menjalankan Aplikasi

1. Pastikan Flutter sudah terinstall.
2. Buka terminal pada folder project.
3. Jalankan:

flutter pub get

4. Kemudian jalankan:

flutter run

## Kendala Setup

Jika aplikasi tidak dapat dijalankan, pastikan Flutter SDK dan
perangkat/emulator sudah dikonfigurasi dengan benar.
